# 📚 শিখি — NCTB Interactive Learning Platform

Bangladesh NCTB Class 1-10 interactive learning website with animations, quizzes and games.

## 🌐 Live Site
**https://iramanorwa.github.io/nctb-shikhi/**

## ✨ Features
- 🎬 Step-by-step Animations for every topic
- 🎮 Interactive Quiz with instant feedback
- 🏆 Progress tracking
- 🔍 Live search across all topics
- 🌐 Bangla + English bilingual
- 📱 Mobile responsive

## 📖 Classes Covered
Class 1 to 10 — All NCTB subjects including Bangla, Math, English, Science, Physics, Chemistry, Biology, History, Geography.

## 🚀 Run Locally
Just open index.html in your browser — no server needed!
